# Visual assets

- `Sources/Luma/Resources/reading-garden.png`: original pixel landscape generated with the built-in image generation tool on 2026-11-01. No reference image. The tool did not expose a selectable or confirmed model identifier, so this repository does not assert a specific image model version.
- `packaging/Luma.icns`: deterministic original pixel book mark generated by `scripts/make-icon.swift` using AppKit.
- Sidebar and feature symbols: original pixel matrices in `Design.swift`.
- No bundled third-party fonts. Interface text uses native system fonts.

The landscape is used as a decorative home banner. Reading content stays on a plain high-contrast surface.

## Generation prompt

Use case: stylized-concept. Asset type: wide decorative banner inside a beautifully designed native macOS reading assistant called Luma. Generate a refined, quiet pixel-art landscape, wide 3:1 horizontal composition. A tiny warm cream reading cottage with illuminated amber window among deep sage and forest green trees on the RIGHT third, subtle terracotta footpath, distant misty sage hills and a soft pale butter sunrise. LEFT half mostly calm warm ivory sky and sparse low hills to provide negative space. Beautiful deliberate chunky pixel clusters, modern artisanal 16-bit game art, restrained palette cream #F5F1E7, dark evergreen #294D3E, muted sage #AAB8A0, burnt orange #C66D42. No text, no lettering, no watermark, no UI, no gradients or photographic texture. Relaxed mature editorial mood, not childish. Crisp pixels, no blurry edges.
